| --- | --- | --- |
| Manager | Specialist 선택·결과 통합·최종 답변 | 사용자 대화를 계속 담당 |

| Security Specialist | 보안 질문만 처리 | Manager에게 결과 반환 |
| Contract Specialist | 계약 질문만 처리 | Manager에게 결과 반환 |
